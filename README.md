# 한자놀이

사단법인 한국어문회 **전국한자능력검정시험**의 급수 기준을 그대로 게임 구조로 옮긴 한자 학습 게임.
시험 대비 앱을 게임처럼 꾸민 것이 아니라, **출제 유형 = 문제 유형 / 급수 = 스테이지 / 모의고사 = 보스전**으로
게임 구조와 시험 구조를 같은 모양으로 만든다.

현재 범위: **8급 → 7급II → 7급 → 6급II → 6급 (누계 300자)**

## 실행

```bash
npm install
npm run dev      # http://localhost:5300
```

`dev`·`build`·`test` 앞에서 획순 데이터를 자동으로 굽는다(`npm run data`). 따로 실행할 필요 없다.

```bash
npm test
```

배정한자·한자어·출제기준의 무결성을 검사한다. 급수별 자 수와 **누계**(50·100·150·225·300), 급수 간 중복,
낱말이 배정한자를 벗어나지 않는지, 300자가 모두 낱말에 쓰이는지, 그리고 **다섯 급수의 모의고사를 실제로
생성해** 문항 수·정답 포함 여부·4지선다 여부까지 확인한다. 데이터를 손으로 고쳤으면 이걸 먼저 돌린다.

## 급수별 기준 (출제기준표 그대로)

| 급수 | 읽기 | 독음 | 훈음 | 반의어 | 완성형 | 동의어 | 동음이의 | 뜻풀이 | 한자쓰기 | 필순 | 계 | 합격 | 시간 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 8급 | 50 | 24 | 24 | – | – | – | – | – | – | 2 | 50 | 35 | 50분 |
| 7급II | 100 | 22 | 30 | 2 | 2 | – | – | 2 | – | 2 | 60 | 42 | 50분 |
| 7급 | 150 | 32 | 30 | 2 | 2 | – | – | 2 | – | 2 | 70 | 49 | 50분 |
| 6급II | 225 | 32 | 29 | 2 | 2 | – | – | 2 | 10 | 3 | 80 | 56 | 50분 |
| 6급 | 300 | 33 | 22 | 3 | 3 | 2 | 2 | 2 | 20 | 3 | 90 | 63 | 50분 |

이 숫자들은 게임 밸런싱으로 건드리지 않는다. `src/exam.ts`의 `EXAMS`가 정본이고, 합계가 총문항과
어긋나면 앱이 뜨는 순간 터진다. 합격 기준은 전 급수 70%.

출처: [출제기준](https://www.hanja.re.kr/kccpt/exam/questInfo.do) · [합격기준](https://www.hanja.re.kr/kccpt/exam/successRule.do)

## 놀이 방식

- **급수 사다리** — 8급부터 시작하고, 그 급수 모의고사에 합격해야 다음 급수가 열린다.
- **한자 정원** — 익힌 한자가 씨앗 → 새싹 → 풀 → 나무 → 꽃으로 자란다. 복습을 미루면 시든다(SM-2 축소판).
  급수 시험은 누적형이라(6급 = 300자 전부) 새로 외우는 것보다 안 잊는 것이 어렵다.
- **소리** — 한자를 누르면 훈음을 읽어 준다(브라우저 내장 음성, ko-KR). 아직 글씨를 못 읽는 아이도 놀 수 있다.
- **미니게임 3종** — 훈음 짝맞추기 · 독음 요격 · 필순 따라쓰기. 전부 그 급수까지의 누계 한자에서 나온다.

## 구조

```
src/
  data/hanja8.ts     8급 50자 + 한자어              ← 손으로 넣는 정본 데이터
  data/grades.ts     7급II·7급·6급II·6급 신규 250자
  data/words.ts      한자어 301개 + 누계 계산
  data/pairs.ts      반의어·유의어·성어(완성형)
  data/strokes.json  획순 (생성물, .gitignore)
  srs.ts             간격 반복 = 한자 정원
  progress.ts        급수증·최고기록
  exam.ts            급수별 모의고사 + 9가지 문제 유형 생성
  games/             훈음·독음·필순 미니게임
  hanjaSvg.ts        획 하나만 강조한 정지 SVG (필순 문제용)
  tts.ts             한국어 음성
test/data.test.ts    데이터·출제기준 무결성 테스트
```

손으로 넣는 것은 **배정한자·한자어·반의어·유의어·성어**뿐이다. 나머지 문제 유형
(독음·훈음·필순·뜻풀이·한자쓰기·동음이의어)과 급수·누계·획수는 전부 계산해서 만든다.

진행 상황은 브라우저 `localStorage`에 저장된다 (`hanja-nori.srs.v1`, `hanja-nori.progress.v1`).

## 알려진 제약

- **敎 飮 窓 淸** 네 글자는 획순 데이터에 한국 정자가 없어 중국 자형(教·飲·窗·清)으로 대신 그린다.
  자형이 미세하게 달라 **필순 문제와 필순 게임에서는 제외**한다(`NO_PILSUN`). 다른 유형에서는 정상 출제.
- 실제 시험은 주관식이지만 여기서는 전부 4지선다다.
- 부수 데이터가 없다 (부수는 6급에서는 출제되지 않지만 5급II부터 필요).

## 다음 급수를 붙일 때

1. `src/data/grades.ts`에 그 급수의 **신규** 배정한자만 추가
2. `test/data.test.ts`의 `LADDER`에 자 수·누계 추가
3. `src/data/words.ts`에 새 글자가 들어간 낱말 추가 (300자 전수 커버 테스트가 빠진 글자를 알려 준다)
4. `src/exam.ts`의 `EXAMS`에 출제 구성 추가 — **출제기준 원문 표를 보고** 넣을 것
5. `npm test`
